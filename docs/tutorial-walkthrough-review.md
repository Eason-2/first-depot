# Codex 零基础跟练复盘 · 2026-10-27

## 目标与交付

沿用用户已确定的 Windows 默认、Mac 可切换、账号/API 双路线和蓝白配色。六章被拆成 17～20 个操作屏（依系统和路线变化），每屏提供可对照的操作画面、自己电脑上要做的动作、完成标志。原完整文字与排错保留为折叠参考，新闻与成长记录不变。

Node.js 下载区包含四张真正的官网局部截图：Windows/Mac × 桌面/手机。其他窗口是明确标注的 HTML 示意，不能声称是实机操作截图。环境变量演练仅用固定无效值，没有密钥输入框、存储或 API 调用。

## 逐轮发现与修正

1. **下载系统会选错。** 官网会按照访客环境选择系统，URL 参数不足以切到 Windows。实际操作下方系统、架构选择器后截图，核对安装包链接。
2. **手机截图字太小。** 桌面截图缩小后控件不可读。改为在 390px 宽度重新实拍，以 `<picture>` 提供手机图，保留原图放大链接。
3. **会复制命令不代表知道在哪执行。** 补上搜索终端、普通打开、提示符、粘贴与回车。区分终端命令、nano 配置文件内容、Codex 对话输入。
4. **配置写好了仍可能读不到。** Windows 单列重开终端与存在性检查；Mac 单列隐藏输入、export、同窗口登录与 `.zprofile` 保存。演示不回显真实 Key。
5. **看完页面不等于安装成功。** 末屏显示本章自查，明确只是读者勾选。最后以真实回复为准，并增加下次重新打开的步骤。
6. **换路线后旧状态会误导。** 切换系统或登录方式重置操作屏与自查，并清理不匹配的片段地址；指定操作屏的链接可恢复对应路线。

- Windows 全新机器从下载安装到真实请求的完整实装。

下一次验收应找未接触过 Codex 的读者，在自己的 Windows 电脑从首页开始。只记录每次停顿的操作屏、误解的按钮/名词、实际报错与是否收到回复；记录时去掉账号与密钥。优先补这些卡点的实拍图，随后重跑现有检查。读者能独立重开并发出第二条消息，才把真人跟练这一项记为通过。
